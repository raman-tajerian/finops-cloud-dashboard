# Apple/Stripe light-mode overhaul

## Scope
- Replace the dark green canvas and glass treatment with Apple-style light gray and pure-white surfaces.
- Rework every dashboard surface, metric, chart, badge, control, and table for crisp graphite text and cool-gray hierarchy.
- Preserve all existing FinOps data, responsive bento structure, and interactions.

## Visual system
- Canvas `#F5F5F7`; white cards with subtle gray borders and soft shadows.
- Inter/SF Pro/Helvetica Neue typography with strong tabular metrics.
- Dark graphite primary actions and restrained Stripe purple for selected states and chart emphasis.
- Pastel semantic status badges, generous card padding, and six-unit grid spacing.

## Validation
- Check desktop and mobile layouts, scan controls, budget slider, savings actions, and resource filters.
- Confirm no horizontal overflow, runtime errors, or build errors.
